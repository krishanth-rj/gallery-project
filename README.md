# Image Gallery Website 🖼️

A styled and responsive image gallery built using **HTML and CSS**.  
This project focuses on layout design, styling, and visual presentation of images.

---

## 📌 Features

- Grid-based image gallery layout
- Responsive design for different screen sizes
- Hover effects on images
- Clean and minimal UI
- Organized folder structure

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- Tailwind CSS  
- Git & GitHub
